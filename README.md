# AGF 2026 업체별 전체 카탈로그 — 작품별 연동

- 기존 23개 업체를 **🎮 게임(9)** / **🎨 피규어·애니(14)** 로 구분했습니다.
- 업체 선택 → 판매 상품 / 이벤트·무료 경품 탭 → 기존 전체 카탈로그 이미지를 표시합니다.
- 니케 판매 상품 탭에 **지니뮤직의 종합 굿즈 카탈로그**를 별도 구획으로 함께 표시합니다.
- 니케 이벤트 탭에도 지니뮤직 구매 특전 이미지를 별도 구획으로 표시합니다.
- 지니뮤직 원래 업체 메뉴에서도 같은 이미지를 그대로 사용합니다. 이미지 복제 없이 파일 경로만 참조합니다.
- 지니뮤직의 종합 안내 이미지에는 니케 외 상품이 포함될 수 있으므로 안내 문구를 표시합니다.
- 기존 `catalog.json`, `events.json`, `assets/`를 보존했습니다. 개별 상품 카드, 모의 구매, 장바구니, 합계 계산, X 자동 수집은 없습니다.
- 업체 상단 공식 X 링크를 강조하고, 배치도 아래에는 AGF 공식 X만 남깁니다.

## 새로운 사진 추가

`assets/`에 사진을 넣고 `company_catalogs.json`의 `sales_images` 또는 `event_images` 배열에 파일명을 추가하세요. 타 업체의 작품 관련 이미지를 연결하려면 해당 작품 업체의 `related_catalogs`에 판매 업체와 이미지 파일명을 추가하면 됩니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

GitHub 업로드 시 기존 JSON과 이미지가 더 최신이라면 해당 파일은 덮어쓰지 말고 새 설정과 병합하세요.
