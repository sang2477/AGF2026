# AGF 2026 업체별 카탈로그 · 계산기 · 부스 위치

## 주요 업데이트
- 아주르 프로밀리아 판매 카탈로그: 사용자가 올린 새 통합 이미지로 교체
- 아주르 프로밀리아 이벤트: 사용자가 올린 스탬프 랠리 안내 이미지로 교체
- 기존 배치도 아래에 신규 상세 배치도 추가
- `agf.zip`의 사진을 판매 상품 / 이벤트·경품으로 구분하여 업체별 배치
- 업체 페이지 상단에 공식 배치도에서 확인된 부스 코드 표시
- 이전 계산기, 공식 X 링크, 기존 JSON/이미지 보존

## 사진 분류 참고
- `company_catalogs.json`에서 `sales_images`와 `event_images`를 수정 가능
- 일부 사진은 굿즈와 특전이 한 장에 함께 실려 있어 주된 목적에 따라 분류
- 중복 이미지는 한 번만 저장
- 부스 코드는 `booth_locations.json`에 저장. 업로드된 공식 지도에서 확인된 코드만 기록
- 지도에 없는 업체는 부스 위치 미확인으로 표시
- X 링크를 확인할 수 없는 새 업체는 임의로 링크를 생성하지 않음

## 실행
`pip install -r requirements.txt`
`streamlit run app.py`

GitHub에는 ZIP 내부의 파일과 폴더를 저장소 최상단에 업로드하세요.
